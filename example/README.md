# community_flutter_stamp_composite_example

Example app and integration tests for `community_flutter_stamp_composite`.

- `lib/main.dart` composites the bundled 48 MP test JPEG to 4000 px with a stamp band.
- `integration_test/composite_test.dart`: sizes, EXIF orientation 1/3/6, extraRotation, mirror, cover crop,
  overlay rows, EXIF/GPS read back (independent parser in `exif_reader.dart`), NOT_FOUND, the OOM retry, timings
  (`STAMP_TIMING` lines).
- `assets/` is generated by `../tool/make_test_assets.py`.

```sh
flutter test integration_test/composite_test.dart -d <device>
(cd android && ./gradlew :community_flutter_stamp_composite:testDebugUnitTest)   # Kotlin math
../tool/test_swift_transform.sh                                                  # Swift math, host-side
```
